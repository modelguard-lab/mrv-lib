mrv.pipeline -- Internal CLI backend
====================================

.. note::

   ``mrv.pipeline`` is the internal labels-first backend behind the ``mrv`` CLI
   (``mrv init`` / ``mrv download`` / ``mrv run``). It is **not** the
   recommended public Python API. For programmatic use prefer the top-level
   typed validators :func:`mrv.rep_invariance_validator` and
   :func:`mrv.res_invariance_validator` (see :doc:`../quickstart`).
